# BTrace project website

This is the `gh-pages` branch for [BTrace](https://github.com/btraceio/btrace).
The site is static HTML, CSS and JavaScript, served directly with `.nojekyll`.
The landing page follows the supplied BTrace 3.0 Landing v2 design and uses the supplied icon set and seven recorded demos.

See [Website maintenance](docs/Website.md) for editing, rebuilding and previewing the site.
The Java implementation and current product documentation live on [`develop`](https://github.com/btraceio/btrace/tree/develop).
