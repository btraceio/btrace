06 // Production

Attach safely to production JVMs.

Check the JVM before you load a probe. When the client detaches, the probe has no cost.

01

Prepare

-javaagent:btrace.jar=port=0

Start the JVM in prepared mode. It listens on localhost only, requires a token, and instruments nothing.

02

Check

btrace doctor <pid>

Reports whether the JVM is ready, with a scriptable exit code. Loads nothing.

03

Attach and detach

btrace <pid> HotPathProbe.java

The client finds the endpoint and token by itself. On exit, the original bytecode is restored.
